# Project Principles

European Banking Risk Analytics is an open research repository guided by the following principles.

1. Prefer official and primary sources whenever possible.

2. Every material regulatory statement should be traceable to its source.

3. Regulatory definitions, summaries and personal analytical interpretations must remain clearly distinguishable.

4. Every dataset must be documented with its source, URL, version, publication date, download date and known limitations.

5. Raw data used in published analyses must remain identifiable through a saved version, checksum or equivalent record.

6. Every analytical result should be reproducible from documented data and code.

7. Prefer clarity and correctness over unnecessary technical complexity.

8. Build reusable knowledge before reusable code.

9. Deliver the project incrementally through small, complete and reviewable outputs.

10. Keep the repository useful to risk professionals, data analysts, researchers, students and recruiters.

11. Chapters may reference the Knowledge Base. Knowledge Base documents must remain independent from the chapters.

12. Bibliographic references must use a single centralized source of truth.

13. Large raw and processed datasets should not be committed to Git unless explicitly justified.

14. Relevant changes should follow a branch, pull request and merge workflow to preserve review history.
